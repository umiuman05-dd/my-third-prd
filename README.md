 Third PRD - CampusTrack

 Project Title
CampusTrack - Simple Student Result Management System

 Description
CampusTrack is a Java console application that manages student semester
details. It accepts student information, course selection, academic marks,
attendance and fee details.

The program validates inputs, calculates total marks and average, determines
academic result and grade, checks attendance and fee status, and displays the
final semester status.
